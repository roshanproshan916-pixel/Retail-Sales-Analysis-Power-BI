# 📊 Retail Sales Analysis using Excel & Power BI

## 📌 Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel and Power BI. The project includes data cleaning, data validation, analysis, and interactive dashboard development.

The main objective is to transform raw retail sales data into meaningful business insights using Excel-based analysis and Power BI visualizations.

---

## 🎯 Objectives

- Clean and preprocess the retail sales dataset
- Identify and handle duplicate and blank records
- Check and handle missing values
- Perform data validation and quality checks
- Analyze sales and profit performance
- Analyze regional and category-wise sales
- Identify monthly sales trends
- Analyze order status and customer-related information
- Create an interactive Power BI dashboard
- Generate meaningful business insights

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Power Query
- Microsoft Power BI
- DAX
- Data Visualization

## 🧹 Excel Data Cleaning

The retail sales dataset was cleaned and validated before performing the analysis.

The major data cleaning and validation steps included:

- Duplicate records check
- Blank rows check
- Missing values check
- Gender final validation
- Order status final validation
- Age value validation and correction
- Days-to-ship outlier check
- Data consistency checks

The cleaned dataset is available in:

`Excel/Retail_Sales_Cleaned.xlsx`

---

## 📊 Excel Analysis

Excel was used for data analysis and summary generation using Pivot Tables.

The analysis includes:

- Category-wise Sales
- Monthly Sales Trend
- Order Status Summary
- Region-wise Sales
- Region-wise Profit

---

## 📈 Power BI Dashboard

The cleaned data was further analyzed using Microsoft Power BI.

The dashboard includes:

- Retail Sales Overview
- Sales & Profit Analysis
- Customer & Order Analysis
- Order Details
- Interactive filters and slicers
- Regional performance analysis
- Sales and profit analysis
