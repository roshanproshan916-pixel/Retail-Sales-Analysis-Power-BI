# 📊 Retail Sales Analysis using Excel & Power BI

## 📌 Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel and Power BI. The project includes data cleaning, data transformation, analysis, visualization, and the development of an interactive Power BI dashboard.

The cleaned retail sales dataset was prepared using Excel, and the processed data was further analyzed and visualized using Power BI to generate meaningful business insights.

---

## 🎯 Objectives

* Clean and prepare the retail sales dataset.
* Identify and handle duplicate and missing values.
* Perform data validation and transformation.
* Analyze retail sales performance.
* Create meaningful KPIs and DAX measures.
* Develop an interactive Power BI dashboard.
* Identify useful sales and business insights through data visualization.

---

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning and preparation
* **Power Query** – Data transformation
* **Microsoft Power BI** – Data analysis and visualization
* **DAX** – Measures and calculations

## 🧹 Data Cleaning

The following data cleaning and validation activities were performed:

* Duplicate records check
* Blank row check
* Missing value analysis
* Gender validation
* Order status validation
* Age value correction
* Days-to-ship outlier check
* Final data quality verification

## 📊 Power BI Dashboard
